# Guía de Entrega del Proyecto Final

¡Felicidades por llegar al proyecto final del Mes 4!

Este proyecto tiene como objetivo aplicar todos los conocimientos adquiridos durante el módulo de preparación de datos. Trabajarás con un conjunto de datos real y desarrollarás un pipeline completo de limpieza, transformación y preparación de datos para dejar un dataset listo para entrenar modelos de Machine Learning.

> **Importante:** Antes de comenzar, lee cuidadosamente el documento **Proyecto_Final_Prediccion_Abandono_Clientes.pdf**, ya que allí se encuentran las instrucciones técnicas del proyecto.

---

# Requisitos de entrega

Para que tu proyecto sea evaluado, deberás cumplir con los siguientes requisitos:

## 1. Crear un repositorio en GitHub

- Crea un repositorio público.
- Sube todos los archivos correspondientes al proyecto.
- Mantén una estructura de carpetas organizada.

---

## 2. Documentar tu proyecto

El repositorio debe incluir un archivo **README.md** donde expliques de forma breve:

- Objetivo del proyecto.
- Dataset utilizado.
- Pasos principales realizados durante el análisis y preparación de los datos.
- Herramientas utilizadas.
- Conclusiones obtenidas.

---

## 3. Reflexión personal

Incluye una sección titulada **"Retos encontrados y aprendizajes"**, donde respondas brevemente:

- ¿Cuál fue la parte más desafiante del proyecto?
- ¿Cómo resolviste ese desafío?
- ¿Qué aprendiste durante el desarrollo del proyecto?

No existe una respuesta correcta. El objetivo es reflexionar sobre tu proceso de aprendizaje.

---

## 4. Antes de entregar

Verifica que:

- El proyecto se ejecuta correctamente.
- No existen errores en el código.
- Los archivos solicitados fueron generados correctamente.
- El repositorio contiene toda la documentación requerida.
- El README está actualizado.

---

# Buenas prácticas

Durante el desarrollo del proyecto procura:

- Utilizar nombres descriptivos para variables y archivos.
- Mantener una estructura de carpetas organizada.
- Realizar commits con mensajes claros y descriptivos.
- Comentar únicamente el código cuando sea necesario.
- Mantener un código limpio y fácil de entender.

---

# Entrega

Comparte únicamente el enlace de tu repositorio de GitHub a través del medio indicado por el instructor antes de la fecha límite de entrega.
